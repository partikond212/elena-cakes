# Демо: Кондитерская мастерская Елены — задания на доработку

Запуск:
```
npm install
npm run dev
```

Все данные (название, телефон, торты, начинки, отзывы) лежат в `src/data.js`.
Для следующей кондитерской меняешь в основном его.

Недоработки помечены в коде комментарием `НЕДОРАБОТКА №`. Ищи по всему проекту.
Иди по порядку: от лёгких к сложным.

---

## Лёгкие

**№2. Фильтр каталога** (`Catalog.jsx`)
Кнопки переключаются, но торты не фильтруются. Отфильтруй `cakes` по `active`.
Бонус: оберни сетку в `AnimatePresence` и добавь `layout` на карточки, чтобы они красиво перестраивались.

**№3. Фото вместо градиентов** (`data.js`, `Catalog.jsx`)
Добавь в каждый торт поле `image`, положи фото в `public/cakes/` и выведи `<img>` с `object-fit: cover` и `loading="lazy"`.

**№7. Подвал** (`Footer.jsx`)
Подставь реальные контакты в `data.js`. Добавь карту: Яндекс Карты → «Поделиться» → «Встроить карту» → `<iframe>`.

**SEO** (`index.html`)
Заголовок «Торты» слабый. Сделай `<title>` вида «Торты на заказ в Динской — мастерская Елены Кунеевской», добавь `<meta name="description">` и Open Graph (`og:title`, `og:image`), чтобы ссылка красиво выглядела в WhatsApp.

## Средние

**№1. Мобильное меню** (`Header.jsx`, `index.css`)
На ширине < 600px меню не влезает. Сделай бургер: кнопка открывает выезжающую панель (анимация через `motion` + `AnimatePresence`), клик по ссылке закрывает меню.

**№4. Форма заказа** (`OrderForm.jsx`)
- Обязательные поля: имя, телефон, дата. Покажи ошибки под полями.
- Дата не раньше, чем через 2 дня от сегодня (атрибут `min` + проверка).
- Вес от 1 до 10 кг.
- Вместо `console.log` собери текст заявки и открой `https://wa.me/<номер>?text=<encodeURIComponent(текст)>`. Так заявка сразу прилетит Елене в WhatsApp, без бэкенда.

**№8. Плавающая кнопка WhatsApp** (`App.jsx`)
Круглая кнопка в правом нижнем углу, появляется после скролла hero (`useScroll` + `useMotionValueEvent`).

**Адаптив < 600px** (`index.css`)
Каталог, начинки и форма в одну колонку, `.form-row` в одну колонку, уменьши паддинги `.section` и `.order-wrap`. Проверь всё в DevTools на iPhone SE (375px).

## Сложные

**№5. Слайдер отзывов** (`Reviews.jsx`)
На мобильном сделай свайп: `motion.div` с `drag="x"` и `dragConstraints`, или CSS `scroll-snap`. Добавь ссылку «Все отзывы на Яндекс Картах».

**№6. Торт** (`Cake.jsx`)
- Добавь 5–8 крошек: маленькие круги, которые появляются у места разреза и падают на тарелку при отъезде кусочка (свой `useTransform` на `y` и `opacity` для каждой).
- Уважай `prefers-reduced-motion`: хук `useReducedMotion()` из framer-motion; если true — кусочек сразу стоит в конечном положении, без анимации.
- Бонус: на мобильном, где скроллить hero быстро, кусочек отъезжает слишком резко. Поиграй с диапазоном `[0, 0.5]`.
